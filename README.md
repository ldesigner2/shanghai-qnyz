上海青年驿站实时房源地图
一个纯前端单文件网页工具，把上海个人可预约的青年驿站全部标在地图上，支持实时房源查询、日期筛选、自动监控和Bark推送。

 功能
 📍 地图总览
- 个人可预约驿站全部标注在高德地图上
- 绿色标记=有房可约，灰色标记=满房/未上架
- 按旅游便利性排名（外滩/静安寺/武康路附近排前面）
- 点击标记弹出驿站详情（名称、区域、地址、剩余房间数）

 📅 日期房源查询
- 选择入住和离店日期，一键查出该时间段所有可住的驿站
- 右侧列表只显示有房的驿站，按排名排序
- 不用再一家家点进公众号看日历了

 🔔 自动监控 + Bark推送
- 看中哪家就点旁边的☆铃铛收藏
- 每60秒自动轮询官方接口
- 满房突然放出空房时，自动推送到手机（通过Bark App）
- 监控日志实时记录每次查询结果

 🗺️ 筛选功能
- 按区域筛选（黄浦、静安、徐汇、长宁等热门区排前面）
- 按排名分组筛选（1-10名顶级推荐、11-20名市中心优选等）
- 搜索框按名称或区域关键词搜索
- 一键显示全部恢复默认

 使用方法

 在线使用
直接访问上方链接（GitHub Pages），手机电脑都能用。

 本地使用
下载到本地双击用浏览器打开即可，无需安装任何东西。

 Bark推送设置（可选）
1. 手机App Store下载 **Bark**
2. 打开Bark，复制你的Key（格式类似 `XXXXXXXXXXXX`）
3. 粘贴到网页左侧"Bark Key"输入框
4. 选好入住离店日期，点☆收藏要监控的驿站
5. 点"开始监控"，有房了Bark会推送通知到你手机

 注意事项

- 数据来源：上海青年驿站官方接口
- 监控需要保持网页打开，手机锁屏后浏览器会暂停后台JS
- Bark推送需要手机安装Bark App并保持通知权限
- 本工具仅供个人学习使用，房源信息以官方公众号为准
